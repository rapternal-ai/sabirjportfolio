# PROJECT: Sabir Jihad – Director Portfolio Page

## GOAL
Build a clean, single-page portfolio website that presents Sabir Jihad as a Digital Product & Experience Leader. The page should emphasize leadership, systems thinking, and execution across content, design, and engineering.

The design should feel:
- Professional
- Minimal
- Institutional (similar to financial or government sites)
- Clean typography, strong spacing, no heavy visuals

---

## DESIGN SYSTEM

### Colors
- Background: #f5f2ed (champagne)
- Primary text: #001f33 (midnight)
- Secondary text: #42515a (smoke)
- Accent: #41a8df (island blue)

### Typography
- Font: Inter or system sans-serif
- Headings: bold, large, spaced
- Body: clean, readable

### Layout
- Max width: 900–1100px centered
- Generous vertical spacing
- No heavy borders or shadows
- Subtle dividers between sections
